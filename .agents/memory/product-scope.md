Keep the Online Examination System limited to the student-facing frontend. Use clearly labeled sample records and a replaceable browser-only mock service; do not add backend APIs, database behavior, admin/teacher dashboards, or question/assignment management.

**Why:** The user explicitly specified a student-only frontend prototype with no backend or administrative interfaces.

**How to apply:** Keep new features within the student journey (sign-in, assigned exams, attempts, submissions, results, history, profile, notifications). Do not claim browser-only timing or monitoring is tamper-proof.
